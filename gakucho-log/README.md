# 学長AIの記録

リベシティの学長AIチャットは履歴が残らないので、**スクショ → 文字起こし → スマホで見返せるページ** にして残すための仕組みです。
このブログ（Astro）のビルドや公開ページとは切り離してあり、`gakucho-log/` の中だけで完結します。

見るページ（非公開・自分だけ）:
https://claude.ai/code/artifact/df1749d9-8236-445d-83b9-58df92f4067b

Android のブラウザで開いてホーム画面に追加しておくと、アプリのように使えます。

## 毎回の流れ

1. **その場で残す**（Android）
   学長AIとのやり取りを、会話の頭から順にスクショします。ページをリロードするとチャットは消えてしまうので、**会話が一区切りついたらその場で**撮るのが安全です。
   Android 12 以降なら、スクショ後に出る「キャプチャ範囲を拡大」を使うと長い回答も1枚に収まります。
   スクロールしながら撮るときは、**前の画面の最後の数行が次の画面にも入るように**少し重ねて撮ると、文字起こしのときにつなぎ目で抜けが出ません。
2. **Claude に渡す**
   Claude Code のセッションでスクショを貼り付けて `/gakucho` と入力するか、「学長AIログに追加して」と伝えます。
   スクショの代わりに、**チャット画面を長押しで選択してコピーしたテキスト**を貼り付けてもかまいません（こちらのほうが読み取り違いが出ないので確実です）。
3. **あとはこちらで処理します**
   - スクショを読んで、質問と回答に分けて `logs/YYYY-MM-DD-〇〇.md` を作成
   - `node gakucho-log/build.mjs` でビューアを作り直し
   - 上のページを同じURLのまま更新
   - リポジトリにコミット＆プッシュ
4. **スマホで開く**
   ページを開けば、新しい会話が一番上に追加されています。

## ページでできること

- キーワード検索（**回答の本文まで**検索して、該当箇所を黄色くハイライト）
- タグで絞り込み
- 会話をタップして開く／閉じる、「全部ひらく」
- スマホの設定に合わせてライト／ダークで表示
- **「文面をぼかす」** — 吹き出しの中身にぼかしをかけた状態でスクショを撮るためのモード。
  ぼかし中に吹き出しをタップすると、そこだけ表示できます（見せたい1つだけ出す使い方）。
  タイトル・日付・タグはぼかしません。

> ぼかしは画面表示だけの加工です。ページのURLを渡すと相手はぼかしを解除できてしまうので、
> 人に見せるときは **スクショを撮って、その画像を渡してください**。

## ファイルの形式

`logs/` に会話ごとに1ファイル置きます。ファイル名は `YYYY-MM-DD-短い名前.md`。

```markdown
---
title: 一覧に出す見出し（会話のお題）
date: 2026-08-18
tags: [NISA, 投資]
source: リベシティ 学長AIチャット   # 省略可
note: 3枚目のスクショが途中で切れている   # 省略可。文字起こしの補足
---

## 自分

質問した内容をそのまま書きます。
段落は空行で区切ります。

## 学長AI

回答をそのまま書きます。

## 自分

続きの質問。

## 学長AI

続きの回答。
```

- 見出しは `## 自分` と `## 学長AI` の2種類だけ（`## 私` `## 学長` `## AI` も同じ扱い）。
- 太字や箇条書きなどの記法は使わず、見たままのテキストで書きます。
- 誤字を見つけたら `.md` を直して、下のコマンドで作り直せば直ります。

## 手動でビューアを作り直す

```sh
node gakucho-log/build.mjs
```

`gakucho-log/dist/index.html` が書き変わります。このファイル単体でも動くので、ブラウザで直接開いても読めます。
（`dist/` はリポジトリの `.gitignore` 対象なので、クローンし直したときはこのコマンドで作り直してください。文字起こし本体は `logs/` に残ります。）
書式に間違いがあるとエラーで止まり、どのファイルのどこが悪いか表示されます。

## 人に配る版（app/）

`app/index.html` は、これとは別に用意した**配布用の1ファイル版**です。
Claude Code もリポジトリも使わず、ブラウザだけで貼り付け・保存・検索ができます。
配り方や記事に書くべき注意は `app/README.md` にまとめてあります。

## 気をつけること

- 文字起こしは読み取り違いが起きえます。お金の判断に関わる数字は、元のスクショか学長AIで確認してください。
- リベシティは有料コミュニティです。このページは既定で非公開（自分だけが見られる状態）です。共有リンクは配らないでください。
- 元のスクショ画像はこのリポジトリには入れていません（残したい場合は手元かクラウド写真に置いたままにしてください）。
