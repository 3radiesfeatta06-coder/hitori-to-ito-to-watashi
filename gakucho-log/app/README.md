# ログのこし（配布用）

**公開先: https://lognokoshi.pages.dev**（Cloudflare Pages / ダイレクトアップロード）
更新するときは、同じプロジェクトで「新しいデプロイを作成」から `index.html` を差し替える。URLは変わらない。

`index.html` **1ファイルだけ**で動く、AIとの会話を残しておくためのメモ帳です。
インストール・ログイン・サーバー不要。記録は使う人の端末のブラウザ（localStorage）にだけ保存されます。

`gakucho-log/` の自分用の仕組み（Claude Code ＋ Markdown）とは別物で、こちらは**人に配るためのもの**です。

## 使う人の流れ

1. ページを開く（またはHTMLファイルを開く）
2. AIとのやり取りをコピーして「＋ 会話を追加」
3. 貼り付けて「発言に分ける」→ 自分／相手が交互に割り当てられる（違うところは話者ボタンで入れ替え）
4. タイトルと日付をつけて保存
5. あとからキーワード検索。人に見せるときは「文面をぼかす」でスクショ
6. 設定画面で**配色を4種類**（もり／すみ／みなも／ぶどう）と明るさ（端末に合わせる／ライト／ダーク）を選べる

## 配り方

### A. URLを公開して配る（おすすめ）

記事にリンクを貼るだけで済み、更新も差し替えるだけです。

**GitHub Pages の場合**

1. 新しい公開リポジトリを作る（例: `log-nokoshi`）
2. `index.html` をそのまま置く（この README は不要）
3. Settings → Pages → Source を `Deploy from a branch` / `main` / `/ (root)` にする
4. 数分後 `https://<ユーザー名>.github.io/log-nokoshi/` で公開される

**Cloudflare Pages の場合**

1. Cloudflare にログイン → Workers & Pages → Create → Pages → Upload assets
2. `index.html` を入れたフォルダをドラッグ＆ドロップ
3. 発行された `https://〇〇.pages.dev` を配る

どちらも無料枠で足ります。読者には「開いたらホーム画面に追加してください」と案内すると使ってもらいやすいです。

### B. HTMLファイルそのものを配る

Google Drive などに置いてリンクを共有します。オフラインでも動きますが、
「ダウンロードしてから開く」のひと手間があるぶん、スマホの人はつまずきやすいです。
Aと併用して「保存版が欲しい人はこちら」として置くのがちょうどいいです。

## 記事に必ず書いておきたいこと

- **記録は端末のブラウザにだけ保存されます。** 機種変更・ブラウザのデータ削除・シークレットモードでは消えます
- **ときどき「ファイルに書き出す」でバックアップを。** 新しい端末では「読み込み」で復元できます
- **ブラウザごとに別々に保存されます**（Chromeで入れた記録はSafariには出ません）
- どこにも送信されないので、内容が外に出る心配はありません（この点は安心材料として書くと伝わります）

## 手直しするところ

| 変えたいもの | 場所 |
|---|---|
| アプリ名 | `<title>` と `<h1 id="app-title">`、`.eyebrow`、フッター |
| 説明文 | `.lede` の一文 |
| 相手の名前の初期値 | `defaultState` の `partnerName`（アプリの設定画面からも変更可） |
| 配色を足す・変える | CSS 先頭の `[data-palette='〇〇']`（明るい方）と `.dark[data-palette='〇〇']`（暗い方）の組。JS の `PALETTES` にも同じ id と見本用の3色（背景・相手・自分）を足す |
| 明るさの初期値 | `defaultState` の `mode`（`auto` / `light` / `dark`） |
| 配色の初期値 | `defaultState` の `palette` |

## お試し版について

Artifact で公開したお試し版では、**「ファイルに書き出す」だけ動きません**（閲覧環境がダウンロードを止めるため）。
「文字としてコピー」は動きます。自分でURL公開した本番や、HTMLファイルを直接開いた場合は両方動きます。
